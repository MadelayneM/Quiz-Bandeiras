# 🚩 Quiz de Bandeiras

Aplicativo mobile desenvolvido em **Android Studio** com o objetivo de criar um quiz educativo e interativo sobre bandeiras de diferentes países.

## 📌 Sobre o projeto

O **Quiz de Bandeiras** é uma aplicação desenvolvida como projeto acadêmico durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)**.

A proposta do aplicativo é apresentar ao usuário diferentes bandeiras e testar seus conhecimentos por meio de perguntas e alternativas.

Durante o quiz, o jogador pode responder às perguntas, acompanhar sua pontuação e, ao final, consultar seu desempenho no ranking.

O projeto foi desenvolvido com foco na prática de conceitos de **desenvolvimento Android, programação em Java, criação de interfaces com XML e interação com o usuário**.

## 🎯 Objetivo

Desenvolver um aplicativo simples, educativo e interativo que permita aos usuários testar seus conhecimentos sobre bandeiras de diferentes países.

Além da proposta educativa, o projeto teve como objetivo colocar em prática conhecimentos adquiridos durante o curso, principalmente relacionados ao desenvolvimento de aplicações Android e à criação de interfaces para dispositivos móveis.

## 💡 Proposta da aplicação

O usuário inicia o quiz e informa seu nome para participar da atividade.

Em seguida, são apresentadas perguntas acompanhadas de imagens de bandeiras e diferentes alternativas de resposta.

A cada pergunta, o usuário deve selecionar uma alternativa e confirmar sua resposta. Ao longo do quiz, sua pontuação é atualizada de acordo com seus acertos.

Ao finalizar, o usuário pode visualizar seu resultado e consultar o ranking dos participantes.

## 🎨 Interface

A interface foi desenvolvida buscando manter uma aparência simples, organizada e fácil de utilizar.

O aplicativo utiliza elementos visuais para facilitar a identificação das perguntas e das alternativas, além de imagens das bandeiras para tornar a experiência mais interativa.

Entre os principais elementos da interface estão:

- 🏁 Tela inicial
- 👤 Campo para identificação do jogador
- 🌎 Imagens das bandeiras
- ❓ Área das perguntas
- 🔘 Botões de alternativas
- ✅ Botão para responder
- 📊 Sistema de pontuação
- 🏆 Tela de ranking

## 💻 Desenvolvimento

O projeto foi desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)**, proporcionando uma experiência prática com o desenvolvimento de uma aplicação Android.

Durante a construção do aplicativo, foram trabalhados tanto aspectos visuais, como a criação e organização das telas, quanto aspectos de programação, como a lógica das perguntas, respostas e pontuação.
